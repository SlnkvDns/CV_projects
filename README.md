# Computer Vision и Deep Learning

Подборка учебных и экспериментальных проектов по компьютерному зрению: от классической обработки изображений до обучения нейросетей для классификации, регрессии и семантической сегментации. Ноутбуки сгруппированы по теме и переименованы так, чтобы назначение каждого было понятно из структуры репозитория.

## Запуск

Ноутбуки рассчитаны на Jupyter и PyTorch. Набор библиотек зависит от проекта; обычно нужны `numpy`, `pandas`, `matplotlib`, `opencv-python`, `Pillow`, `scikit-learn` и `torch`/`torchvision`. Для сегментации дополнительно используется `segmentation-models-pytorch`. В отдельных ноутбуках есть установка зависимостей прямо в ячейках.

Откройте нужный `.ipynb` в Jupyter или VS Code и подготовьте соответствующие данные. Некоторые ноутбуки были разработаны для Kaggle и содержат пути `/kaggle/input/...`; для локального запуска эти пути нужно заменить на расположение датасета. Ноутбуки обработки изображений также ссылаются на изображения в `../data/`. Данные и веса моделей не включены в репозиторий.

## Примечания

- Результаты в ноутбуках относятся к конкретным запускам и настройкам эксперимента; это не единый воспроизводимый бенчмарк.
- В репозитории сохранены результаты выполнения ячеек там, где они были доступны. Для отдельных экспериментов нужны внешние данные, GPU или предварительно сохранённые веса.
- Альтернативные версии, дубли и эксперименты, не готовые для демонстрации, сохранены в [`_archive/`](./_archive/README.md) и не включены в основной список проектов.
