# Архив черновиков

Эти ноутбуки сохранены для справки, но не входят в основной портфолио-раздел репозитория. Здесь находятся альтернативные/перекрывающиеся версии лабораторных работ по регрессии и сегментации, а также эксперименты с автоэнкодерами, которые зависят от Kaggle-файлов и сохранённых чекпоинтов.
